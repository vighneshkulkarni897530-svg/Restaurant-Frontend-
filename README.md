# 📱 Govinda's Restaurant & Dining — Next.js 14 Frontend Client

Modern mobile-first customer dining portal and staff management dashboard built with Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, and Socket.IO client.

---

## 🚀 Quick Setup & Run

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env.local
```

### 3. Start Frontend Client
```bash
npm run dev
```
*Client runs on `http://localhost:3000`*

---

## ☁️ Deployment on Vercel

- **Framework Preset**: Next.js
- **Root Directory**: `./` (when deployed from dedicated frontend repo)
- **Environment Variables**:
  - `NEXT_PUBLIC_API_URL` = `https://your-backend-api-url.com/api`
  - `NEXT_PUBLIC_SOCKET_URL` = `https://your-backend-api-url.com`
